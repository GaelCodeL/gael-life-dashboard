GAEL · LIFE DASHBOARD (PWA) — PUBLICAR EN GITHUB PAGES

1. En GitHub crea un repositorio nuevo llamado gael-life-dashboard.
2. Elige Public y crea el repositorio.
3. Descomprime este ZIP en tu ordenador.
4. Dentro del repositorio pulsa Add file → Upload files.
5. Arrastra el CONTENIDO de esta carpeta: index.html, manifest.webmanifest, sw.js y la carpeta icons. No subas solo la carpeta exterior.
6. Pulsa Commit changes.
7. Ve a Settings → Pages.
8. En Build and deployment selecciona Deploy from a branch.
9. Selecciona main y /(root), y pulsa Save.
10. Espera a que termine el despliegue. La URL será https://TU-USUARIO.github.io/gael-life-dashboard/

INSTALAR EN IPHONE
1. Abre la URL publicada en Safari.
2. Pulsa Compartir → Añadir a pantalla de inicio → Añadir.

NOTAS
- El sitio es estático, no necesita servidor ni base de datos.
- Las casillas guardan el estado localmente en ese navegador/dispositivo.
- El service worker permite cargar la app sin conexión tras la primera visita.
- En GitHub Free, Pages requiere un repositorio público. La web será accesible públicamente: no incluyas datos personales sensibles.
